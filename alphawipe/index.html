    유의사항

    제거된 메타데이터는 복구할 수 없습니다. 처리 전 원본 파일은 별도로 보관하시기 바랍니다.

    처리 후 파일 용량이 감소하는 것은 정상입니다. 메타데이터 자체의 삭제에 더해, 불투명한 이미지의 경우 데이터가 은닉되어 있던 알파 채널을 제거하고 화소를 재압축하기 때문입니다.

    출력 형식은 내보내기 설정에서 지정할 수 있으며, 원본 형식과 무관하게 선택하신 형식으로 저장됩니다. PNG를 선택한 경우 RGB 화소값이 변경되지 않아 화질 저하가 발생하지 않습니다. WebP 및 JPEG는 재인코딩 과정에서 미세한 손실이 발생하며, JPEG는 투명 영역이 흰색으로 대체됩니다. ‘완전 재구성’ 방식은 형식과 관계없이 투명 영역을 흰색으로 대체하고 색상값을 최대 1만큼 변경합니다.

    모든 처리는 이용자의 브라우저 안에서만 수행됩니다. 이미지와 메타데이터는 서버로 전송되지 않습니다. 이 페이지는 처리 과정에서 어떠한 네트워크 요청도 보내지 않으며, 화면 상단의 ‘NovelAI 공식 사이트에서 확인하기’ 버튼을 직접 누르셨을 때만 새 탭이 열립니다. 한 번 방문하면 오프라인에서도 동작하므로, 인터넷 연결을 끊은 상태로 사용하셔도 됩니다.
