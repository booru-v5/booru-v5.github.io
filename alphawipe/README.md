# 알파 와이프 (웹)

NovelAI 이미지의 메타데이터를 **브라우저 안에서만** 지우고 들여다보는 도구입니다.
안드로이드 앱 *알파와이프* 를 웹으로 옮긴 것으로, 설치 없이 열리고 PWA로 오프라인에서도 동작합니다.

## 두 가지 기능

**정보 지우기** — PNG 텍스트 청크(tEXt/zTXt/iTXt)와 알파 채널 최하위 비트에 숨겨진
`stealth_pngcomp` + gzip JSON 을 모두 제거합니다. 파일명을 암호학적 난수로 바꾸고 ZIP으로 내보냅니다.
출력 형식(WebP·PNG·JPEG)과 화질, 제거 방식(정밀 / 완전 재구성)을 고를 수 있습니다.
제거 후 자체 점검을 돌려 남은 데이터가 없는지 확인하고, 실패한 파일은 내보내기에서 제외합니다.

**정보 보기** — 프롬프트·네거티브·캐릭터별 프롬프트를 나눠서 보여주고, 작가 태그를 따로 분류합니다.
랜덤 프롬프트(`||a|b||`)는 `actual_prompts` 와 대조해 실제 선택된 항목을 역산해 표시하고,
음수 가중치는 점선 테두리로 구분합니다. 태그를 누르면 복사되고, 유형별 일괄 복사도 됩니다.

## 개인정보

**이미지는 어디로도 전송되지 않습니다.** 모든 처리는 브라우저 안에서 일어납니다.

- 소스에 `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` / `EventSource` 호출이 **하나도 없습니다.**
- 외부 호스트를 가리키는 URL은 `https://novelai.net/inspect` **하나뿐**이며, 화면 상단의
  ‘NovelAI 공식 사이트에서 확인하기’ 버튼을 직접 눌렀을 때 새 탭을 여는 용도입니다. 이미지는 넘어가지 않습니다.
- 외부 폰트·CDN·애널리틱스를 쓰지 않습니다. 모든 자원이 이 저장소 안에 있습니다.
- 서비스 워커는 이 앱의 자기 파일만 캐시하며, 이미지는 HTTP 요청이 되지 않으므로 워커가 볼 수 없습니다.

실측: 페이지 로드부터 이미지 처리까지 가로채어 확인한 결과 네트워크 요청 **0건**,
교차 출처 리소스 **0건**이었습니다.

## 브라우저 요건

- `CompressionStream` / `DecompressionStream` — 크롬/엣지 80+, 사파리 16.4+, 파이어폭스 113+
  (없으면 캔버스 재인코딩 방식으로 자동 전환되며, 그 경우 ‘정밀’ 모드의 무손실 PNG 경로를 쓸 수 없습니다)
- `공유` 버튼은 Web Share API Level 2를 지원하는 브라우저(주로 모바일)에서만 나타납니다.
- `폴더 저장` 버튼은 File System Access API를 지원하는 브라우저(크롬·엣지 데스크톱)에서만 나타납니다.
- 둘 다 없어도 **ZIP으로 저장**은 모든 브라우저에서 동작합니다.

## 오프라인 / 홈 화면 추가

한 번 열면 서비스 워커가 앱 전체를 캐시하므로 이후에는 인터넷 없이 동작합니다.
브라우저 메뉴의 ‘앱 설치’ 또는 ‘홈 화면에 추가’로 앱처럼 쓸 수 있습니다.

## 작가 사전 출처

작가 분류에 쓰는 사전은 **Danbooru 작가 태그 이름 34,395개**입니다.
태그 *이름 문자열*만 들어 있고 이미지·설명·이용자 정보는 포함하지 않습니다.
Danbooru는 태그 메타데이터를 공개 API와 데이터베이스 덤프로 제공하며, 이를 가공한 태그 목록이
MIT 등으로 널리 재배포되고 있습니다. 원 데이터의 재사용 조건은 Danbooru 이용약관을 따릅니다.
